## 위성 관측 가능성 체크 (착수 전 필수)

사건 기간 전후로 **동일 orbit·동일 관측 geometry**의 Sentinel-1 영상이 존재하는지 먼저 확인한다.
이것이 없으면 Golden Event를 다른 사건으로 교체해야 하므로 최우선으로 검증한다.

- [ ] event 이전 정상영상 (동일 orbit)
- [ ] event 직후 영상 — 침수 잔존 기간 내
- [ ] 동일 계절 과거 3년 baseline 영상 스택
- [ ] event 후 7~21일 Sentinel-2 (구름 비율 확인, 없으면 fallback tier B)

## 표기 규칙

- 산출물은 **최대 침수**가 아니라 **관측시점 침수**로 기술한다.
  SAR 통과 시각이 침수 peak와 어긋날 수 있다는 한계를 화면과 제안서에 명시한다.
- 공식 피해 집계는 **사건 서술과 정성 검증 참고용**이며 모델의 예측 대상이 아니다.
