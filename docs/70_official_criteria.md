# 2026 공모전 공식 심사기준 (확보 완료)

출처: 충청남도 공고 제2026-1565호, 소통24 첨부 `2026년 충청남도 데이터 분석 아이디어 공모전 공고.hwpx`
원문: `docs/90_submission/2026_공모전_공고.txt`, `2026_참가신청_서류.txt` (hwpx 원본 동봉)

D-21 내내 미해결 P0 이었던 항목이다. **전략문서의 추정 배점은 폐기하고 이 표를 쓴다.**

## 1. 배점 — 100점

| 우선순위 | 항목 | 배점 | 내용 |
|---|---|---|---|
| 1 | 창의성 | 10 | 아이디어가 창의적인가 |
| 2 | 필요성 | 20 | 데이터 분석이 현안해결에 필요한가 |
| 3 | 시급성 | 20 | 현안문제가 시급한가 |
| 4 | 적절성 | **25** | 데이터 분석 방법 및 활용 데이터가 적절한가 |
| 5 | 활용성 | **25** | 결과의 활용 방안 및 기대효과 |

동점작은 **배점항목 우선순위**(창의성 → 필요성 → 시급성 → 적절성 → 활용성)로 순위를 가른다.
즉 동점이면 창의성이 먼저다.

## 2. 심사 절차와 가중치

| 단계 | 방식 | 가중치 |
|---|---|---|
| 1차 | 서면 평가 — 2차 대상 결정 | 통과/탈락 |
| 2차 | 내·외부 전문가 각 3인 | **50%** |
| 2차 | 현업부서 실무자 | **20%** |
| 3차 | 온라인 평가 | **30%** |

- 성명·소속은 **블라인드** 처리
- 일정: 접수 ~9/23 → 서면 9/28~10/2 → 전문가·현업 10/6~10/14 → 온라인 10/15~10/23 → 결과 10월 말

## 3. 제출물 — 여기가 가장 중요하다

**기획서는 기타첨부 자료를 포함하여 절대 3페이지를 넘길 수 없다.**

- 필수 서류: 참가 신청서, 아이디어 기획서, 개인정보 동의서, 참가 서약서
- **PDF 로 제출** (위변조 방지), 이메일 `skjang12@dsnw.net`
- 양식 수정 불가. 본문 휴먼명조 10~13pt, 번호는 `1. 가. 1). 가) ○ -` 순
- 첨부파일 누락 시 **별도 안내 없이 탈락**

기획서 목차는 양식에 고정돼 있다.

| 절 | 내용 |
|---|---|
| ① 아이디어 명칭 | 핵심을 파악할 수 있는 제목 |
| ② 분석 목적 | 배경·목적, 중요성·타당성·시급성 |
| ③ 핵심 내용 | 차별성과 독창성 |
| ④ 분석 방법 | 분석방법 구체 서술 + 예상 결과(도표·이미지) |
| ⑤ 필요 데이터 | 활용가능 데이터 목록, 없으면 확보 아이디어 |
| ⑥ 활용방안 | 실제 정책·업무 활용 (as-is / to-be) |

맨 앞의 **아이디어 요약서**가 온라인 평가자(30%)에게 제공된다.

## 4. 공모주제 — 예시가 바뀌었다

| 출처 | 제시된 분야 |
|---|---|

공고의 아이디어 예시도 "노후건물 및 안전등급 미달 건물 분석" 수준이다.

## 5. 우리 작업에 대한 함의

### 유리한 점

- **시급성 20점** — 2026-08-31 호우(도평균 100.2mm, 예산 175.9mm, 10년 내 5위)가
  아직 관측되지 않은 상태다. 제출 시점에 진행 중인 현안이라는 것을 수치로 보일 수 있다.
- **적절성 25점** — 배점 최상위 두 항목 중 하나가 "데이터 분석 방법과 활용 데이터가 적절한가"다.
  실험 01~06 에서 방법을 검증하고 실패한 것을 폐기한 이력이 그대로 근거가 된다.
  다만 3페이지 안에 압축해야 한다.
- 전량 공개데이터, 재현 가능한 파이프라인 — 적절성에 직결.

### 불리한 점 — 정면으로 봐야 한다

- **3페이지 제한이 결정적이다.** 우리가 만든 것은 관측 아카이브 427건, 실험 6건,
  필지 143만 개 파이프라인, WebGIS 다. 이걸 3페이지에 넣을 수 없다.
  **기획서는 시스템 설명서가 아니라 아이디어 제안서여야 한다.**
- **아이디어 공모전이지 개발 공모전이 아니다.** 코드·데모는 제출물이 아니다.
  이미 만든 것은 "실현 가능성의 근거"로만 쓰이며, 그것도 지면이 허락하는 만큼만이다.
- **창의성 10점** — 배점이 가장 낮다. 기술적 정교함으로 얻을 점수가 크지 않다.
- **농업이 공식 예시에서 빠졌다.** 필요성·시급성을 설득할 부담이 그만큼 커진다.
- **온라인 평가 30%** — 도민이 요약서만 보고 이해해야 한다.
  "관측 시점이 판별 가능성을 결정한다"는 명제를 비전문가 언어로 바꿔야 한다.

## 쪽수 실측 (2026-09-03)

양식 원본(`참가신청 서류.hwpx`)의 `header.xml`·`section0.xml` 에서 조판 값을 직접 읽었다.
추정하지 않아도 되는 것을 추정할 이유가 없다.

| 항목 | 값 |
|---|---|
| 용지 | 59528 x 84186 HWPUNIT = A4 |
| 여백 | 좌우 20mm, 상하 15mm, 머리말·꼬리말 5mm |
| 본문 영역 | 170 x 257mm = 96dpi 기준 **643 x 971px** |
| 줄간격 | **160%** (양식에 지배적으로 정의) |

이 조건으로 본문을 앉혀 재는 도구가 `notebooks/check_page_count.py` 다.

### 측정 이력

| 시점 | 쪽수 | 조치 |
|---|---|---|
| 최초 | 3.45 | 그림을 정사각에서 가로 범위로 |
| 그림 가로형 | 3.17 | 문장 압축 1차 |
| 압축 1차 | 3.12 | 문장 압축 2차 |
| 압축 2차 | 3.12 | 중복 항목 4개 삭제, 그림 제목·출처 제거 |
| **현재** | **2.97** | 여유 28px (약 1줄) |

### 두 번 틀렸던 것

**글자수로 어림하면 2.6쪽이 나온다.** 그림과 표가 빠지기 때문이다.

**그림을 뺀 채로 세 번 연속 쟀다.** 측정 도구가 본문의 파일 경로 줄을 그림 삽입
지점으로 삼고 있었는데, 기획서에서 그 줄(제출본에 들어가면 안 되는 내부 메모)을
지우자 삽입이 조용히 실패했다. 0.26쪽이 통째로 빠진 값을 세 번 믿었다.
지금은 `[그림 1]` 캡션을 앵커로 쓰고, 그림이 안 실리면 실행을 중단한다.

### 감도

| 조건 | 쪽수 |
|---|---|
| 10pt / 160% (양식 기준) | **2.97** |
| 10pt / 170% | 3.09 |
| 11pt / 160% | 3.25 |

**글자 크기는 10pt 를 유지해야 한다.** 양식은 10~13pt 를 허용하지만 11pt 로 올리면
바로 넘친다.

### 남은 여유가 얇다

28px 은 약 1줄이다. 양식은 절 제목이 표 칸 안에 들어 있어 실제 한글에서는
여기서 잰 것보다 조금 커질 수 있다. **최종 확인은 한글에서 해야 한다.**
더 줄여야 하면 다음 순서로 덜어낸다.

1. ⑤ 2-나 (현장 피해조사 대조, 1줄) — 없어도 ⑤의 목록은 성립한다
2. ⑥ 3-나 (인력 집중, 2줄) — ⑥ 1 표의 "피해 확인" 행과 겹친다
3. ② 1-나의 라복지구 연도별 수치를 "4년 연속"으로만 (1줄)

### 이번에 덜어낸 것

점수와 직결되므로 무엇을 뺐는지 남겨 둔다.

| 항목 | 이유 |
|---|---|
| ② 2-다 도지사 지시 | 의도 표명이지 측정이 아니다 |
| ② 3-나 2023-07-14 사례 | 3-나의 22% 통계가 같은 말을 수치로 한다 |
| ④ 3-나 연도 제외 검증 | 3-가의 대조군 결과가 강우 반응을 이미 보인다 |
| ⑥ 3-다 배수개선 투자 | ⑥ 2-나와 겹친다 |
| 그림의 제목·출처 줄 | 본문 캡션과 ⑤ 필요 데이터가 같은 말을 한다 |

## 저장소 링크를 넣을 것인가 (결정 필요)

공고 문구는 **"평가 시 성명, 소속은 블라인드 처리하여 실시"** 다.
출품자에게 무엇을 빼라고 요구하는 조항이 아니라, **주최 측이 평가 단계에서 가리는 절차**다.
따라서 저장소 링크가 규정상 금지된 것은 아니다.

현재 기획서 본문에는 성명·이메일·URL이 하나도 없다(자동 확인).

| | 넣는 경우 | 빼는 경우 (현재) |
|---|---|---|
| 적절성·활용성 (50점) | 시제품을 직접 확인할 수 있다 | 문서 안의 측정치로만 판단 |
| 위험 | `github.com/<계정명>` 이 작성자를 드러낸다. 사무국이 걸러 주지 않으면 블라인드가 깨진다 | 없음 |

**권고는 빼는 쪽이다.** 블라인드를 주최 측이 적용하는데 출품자가 신원이 드러나는 링크를
자진해서 넣으면 우회로 보일 수 있다. 기획서는 이미 실측 수치(관측 427회, 필지 143만 개,
판독률 99.1%, 같은 사건 20배)로 구현 사실을 뒷받침한다.

다만 이는 규정 해석이 아니라 판단이므로 **작성자가 정한다.** 넣기로 한다면
⑥ 4. 실현 가능성 끝에 한 줄로 붙이는 자리가 가장 자연스럽다.
